# مدیر تونل GRE شایان

اسکریپت `shayan.sh` برای ساخت و مدیریت چند پروفایل تونل GRE بین سرور ایران و سرور خارج طراحی شده است. هر دو سرور باید پروفایل‌های متناظر داشته باشند و با نقش‌های مخالف تنظیم شوند.

## امکانات

- ساخت پروفایل و رابط GRE، و مدیریت جداگانهٔ هر تونل
- ویرایش تنظیمات، شروع، توقف، راه‌اندازی دوباره، مشاهدهٔ وضعیت و حذف تونل
- انتقال سرویس با TCP، UDP یا هر دو پروتکل
- انتخاب انتقال همهٔ پورت‌ها به‌جز ۲۲ یا تعیین یک پورت دلخواه
- رابط متنی رنگی برای مدیریت پروفایل‌ها

## پیش‌نیازها

- سرور Linux با دسترسی root و Bash
- ابزارهای `ip`, `iptables`, `iptables-save`, `sysctl`, `grep` و `cksum`
- فعال‌بودن عبور پروتکل GRE (IP protocol 47) در فایروال سیستم و پنل ارائه‌دهندهٔ هر دو سرور
- آدرس عمومی قابل دسترس برای هر دو سرور

## راه‌اندازی

1. فایل `shayan.sh` را روی هر دو سرور قرار دهید.
2. اسکریپت را با دسترسی root اجرا کنید: `sudo bash shayan.sh`
3. روی سرور ایران و خارج، پروفایل‌های متناظر بسازید و نقش مناسب هر سرور را انتخاب کنید.
4. روی هر دو سمت، آدرس‌های عمومی، نام رابط، شناسهٔ subnet و GRE Key یکسان وارد کنید.
5. رابط تونل را از بخش Manage روی هر دو سرور بسازید و سپس Start کنید.
6. وضعیت رابط و تنظیمات را با گزینهٔ Status بررسی کنید.

## نکات مهم

- GRE Key باید در هر دو سمت یکسان باشد؛ آن را در اختیار دیگران نگذارید. این کلید به‌تنهایی رمزگذاری ایجاد نمی‌کند.
- گزینهٔ همهٔ پورت‌ها به‌جز ۲۲، ترافیک تمام پورت‌های دیگر را از تونل عبور می‌دهد؛ پیش از فعال‌کردن آن، نیازهای فایروال و سرویس‌ها را بررسی کنید.
- تغییر تنظیمات تونل ممکن است نیازمند ساخت دوبارهٔ رابط در هر دو سرور باشد.
- پیش از استفاده روی سرور اصلی، از تنظیمات فایروال و دسترسی SSH خود نسخهٔ پشتیبان داشته باشید.
