# مدیر تونل GRE شایان

اسکریپت `shayan.sh` برای ساخت و مدیریت چند پروفایل تونل GRE بین سرور ایران و سرور خارج طراحی شده است. برای هر تونل، روی هر دو سرور پروفایل متناظر با نقش‌های مخالف بسازید.

## امکانات

- ساخت و مدیریت چند پروفایل و رابط GRE
- ویرایش تنظیمات، Start، Stop، Restart، مشاهدهٔ Status و حذف تونل
- انتقال سرویس با TCP، UDP یا هر دو پروتکل
- انتقال همهٔ پورت‌ها به‌جز ۲۲ یا انتخاب پورت دلخواه
- رابط متنی رنگی برای مدیریت پروفایل‌ها

## پیش‌نیازها

- سرور Ubuntu/Debian با دسترسی `root` و Bash
- عبور پروتکل GRE (IP protocol 47) در فایروال سیستم و پنل ارائه‌دهندهٔ هر دو سرور
- آدرس عمومی قابل دسترس برای هر دو سرور
- برای مخزن خصوصی، دسترسی SSH به مخزن یا GitHub CLI با دسترسی خواندن محتویات مخزن

## نصب روی هر دو سرور با SSH

برای هر سرور، یک کلید SSH با دسترسی فقط‌خواندنی به مخزن تنظیم کنید. کلید خصوصی را در مخزن یا این README قرار ندهید. سپس با همان حساب کاربری که کلید SSH آن به GitHub دسترسی دارد اجرا کنید:

```bash
sudo apt update
sudo apt install -y git iproute2 iptables procps grep coreutils
git clone git@github.com:shayan9023/shayan-gre-tun.git
cd shayan-gre-tun
sudo bash shayan.sh
```

## اجرای مستقیم با دستور خطی

این مخزن خصوصی است؛ دستور `curl` به نشانی `raw.githubusercontent.com` بدون احراز هویت به فایل دسترسی ندارد. برای اجرای خطی مشابه، GitHub CLI را نصب و با حسابی که فقط دسترسی خواندن فایل‌های مخزن را دارد وارد کنید (`gh auth login`). سپس روی هر سرور اجرا کنید:

```bash
tmp=$(mktemp) && gh api -H 'Accept: application/vnd.github.raw+json' repos/shayan9023/shayan-gre-tun/contents/shayan.sh > "$tmp" && sudo bash "$tmp"; rc=$?; rm -f "$tmp"; exit "$rc"
```

این دستور فایل را موقتاً دریافت می‌کند و اجرا را با دسترسی root انجام می‌دهد؛ ورودی‌های تعاملی اسکریپت همچنان از ترمینال خوانده می‌شوند. راهنمای رسمی: [GitHub CLI `gh api`](https://cli.github.com/manual/gh_api) و [دریافت محتوای مخزن از REST API](https://docs.github.com/en/rest/repos/contents).

## به‌روزرسانی نسخهٔ کلون‌شده

```bash
cd shayan-gre-tun
git pull
sudo bash shayan.sh
```

در منوی اسکریپت، روی سرور ایران نقش `Iran` و روی سرور خارجی نقش `Foreign` را انتخاب کنید. مقدار GRE Key تولیدشده در سرور ایران را در سمت خارج وارد کنید. رابط تونل را از بخش Manage روی هر دو سرور بسازید و سپس Start کنید. برای اطمینان، Status را در هر دو سمت بررسی کنید.

## نکات مهم

- نام رابط، آدرس‌های عمومی، شناسهٔ subnet و GRE Key باید در هر دو سمت متناظر باشند؛ پروتکل و پورت سرویس را نیز مطابق نیاز تنظیم کنید.
- GRE Key به‌تنهایی رمزگذاری ایجاد نمی‌کند؛ آن را در اختیار دیگران نگذارید.
- حالت همهٔ پورت‌ها، ترافیک همهٔ پورت‌ها به‌جز ۲۲ را از تونل عبور می‌دهد؛ پیش از فعال‌کردن آن، نیازهای فایروال و سرویس‌ها را بررسی کنید.
- تغییر تنظیمات هویت تونل ممکن است نیازمند ساخت دوبارهٔ رابط در هر دو سرور باشد.
- پیش از استفاده روی سرور اصلی، از تنظیمات فایروال و دسترسی SSH خود نسخهٔ پشتیبان داشته باشید.
