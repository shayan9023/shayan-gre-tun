# مدیر تونل GRE شایان

`shayan.sh` یک مدیر متنی برای ساخت و ادارهٔ چند پروفایل تونل GRE بین سرور ایران و سرور خارجی است. روی هر دو سرور اجرا می‌شود و برای هر سمت، نقش جداگانه دارد.

## امکانات

- ساخت و مدیریت چند پروفایل GRE
- ویرایش IPها، GRE Key، پورت، پروتکل و subnet ID
- Start، Stop و Restart رابط موجود؛ مشاهدهٔ Status و حذف رابط یا پروفایل
- انتقال TCP، UDP یا هر دو پروتکل
- انتقال همهٔ پورت‌ها به‌جز ۲۲، یا انتخاب یک پورت سفارشی
- منوی رنگی با تأییدهای حذف و پیام خروج `Good Bye :)`

## پیش‌نیازها

- Ubuntu/Debian یا توزیع سازگار Linux با Bash و دسترسی `root`
- ابزارهای `ip`, `iptables`, `iptables-save`, `sysctl`, `grep` و `cksum`
- دسترسی شبکه برای پروتکل GRE (IP protocol 47) بین هر دو سرور؛ این مورد را در فایروال سیستم و پنل ارائه‌دهنده فعال کنید
- آدرس عمومی قابل دسترس برای هر دو سرور

## نصب و اجرا روی هر دو سرور

این دستور از نسخهٔ فعلی مخزن عمومی فایل را می‌گیرد و اجرا می‌کند. فرمان را در نشست `root` روی هر دو سرور اجرا کنید؛ اگر با کاربر sudo وارد شده‌اید، ابتدا `sudo -i` بزنید.

```bash
apt update
apt install -y curl iproute2 iptables procps grep coreutils
bash <(curl -sSL https://raw.githubusercontent.com/shayan9023/shayan-gre-tun/main/shayan.sh)
```

## ساخت تونل

1. دستور نصب را روی سرور ایران و سرور خارجی جداگانه اجرا کنید.
2. در ساخت پروفایل، روی ایران نقش `Iran` و روی سرور خارجی نقش `Foreign` را انتخاب کنید.
3. در هر دو سمت، نام رابط، IP ایران، IP خارجی و subnet ID را یکسان وارد کنید.
4. GRE Key در سمت ایران به‌صورت تصادفی تولید می‌شود؛ همان مقدار را در سرور خارجی وارد کنید.
5. پورت انتقال و پروتکل `TCP`، `UDP` یا `BOTH` را مطابق نیاز انتخاب کنید. حالت همهٔ پورت‌ها، پورت ۲۲ را مستثنا می‌کند.
6. پس از ساخته‌شدن رابط، از بخش Manage گزینهٔ Start را روی هر دو سرور بزنید و اتصال را با Status بررسی کنید.

## مدیریت و به‌روزرسانی

برای دریافت و اجرای آخرین نسخه، همان دستور نصب را دوباره اجرا کنید. پروفایل‌ها در `/etc/vatan-gre-manager/profiles` نگهداری می‌شوند و با دریافت نسخهٔ جدید حذف نمی‌شوند. در Manage می‌توانید تنظیمات و وضعیت هر تونل را تغییر دهید. Stop رابط و پروفایل را نگه می‌دارد؛ Delete tunnel فقط رابط را حذف می‌کند.

برای حذف کامل، از منوی اصلی گزینهٔ `3) Uninstall manager and managed tunnels` را انتخاب کنید. این گزینه پروفایل‌ها و رابط‌های ساخته‌شده توسط مدیر را حذف می‌کند؛ پیش از تأیید، مطمئن شوید به آن‌ها نیاز ندارید.

## نکات امنیتی

- GRE Key باید در هر دو سمت یکسان باشد. کلید GRE به‌تنهایی ترافیک را رمزگذاری نمی‌کند؛ برای محرمانگی از لایهٔ رمزگذاری جداگانه استفاده کنید.
- حالت همهٔ پورت‌ها تقریباً همهٔ ترافیک ورودی به‌جز SSH روی پورت ۲۲ را از تونل عبور می‌دهد؛ قبل از فعال‌کردن، سرویس‌ها و فایروال را بررسی کنید.
- پورت سفارشی فقط همان پورت و پروتکل انتخاب‌شده را عبور می‌دهد. قواعد انتقال روی سرور ایران اعمال می‌شوند.
- پیش از استفاده روی سرور اصلی از تنظیمات فایروال نسخهٔ پشتیبان بگیرید و دسترسی SSH را حفظ کنید.
