# مدیر تونل GRE شایان

`shayan.sh` یک مدیر متنی برای ساخت و ادارهٔ چند پروفایل تونل GRE بین سرور ایران و سرور خارجی است. روی هر دو سرور اجرا می‌شود و برای هر سمت، نقش جداگانه دارد.

## امکانات

- ساخت و مدیریت چند پروفایل GRE
- ویرایش IPها، GRE Key، پورت، پروتکل و subnet ID
- Start، Stop و Restart رابط موجود؛ مشاهدهٔ Status و حذف رابط یا پروفایل
- انتقال TCP، UDP یا هر دو پروتکل
- انتقال همهٔ پورت‌ها به‌جز ۲۲، یا انتخاب پورت سفارشی
- منوی رنگی با تأییدهای حذف و پیام خروج `Good Bye :)`

## پیش‌نیازها

- Ubuntu/Debian یا توزیع سازگار Linux با Bash و دسترسی `root`
- ابزارهای `ip`, `iptables`, `iptables-save`, `sysctl`, `grep` و `cksum`
- عبور پروتکل GRE (IP protocol 47) در فایروال سیستم و پنل ارائه‌دهندهٔ هر دو سرور
- آدرس عمومی قابل دسترس برای هر دو سرور

## نصب روی هر دو سرور

مخزن عمومی است. روی هر سرور وارد نشست root شوید (یا ابتدا `sudo -i`) و این دستور را اجرا کنید:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/shayan9023/shayan-gre-tun/main/shayan.sh)
```

## راهنمای راه‌اندازی

1. اسکریپت را روی هر دو سرور اجرا کنید.
2. برای سرور ایران نقش `Iran` و برای سرور خارج نقش `Foreign` را انتخاب کنید.
3. IP عمومی هر دو سرور و مشخصات تونل متناظر را وارد کنید. GRE Key سمت ایران را در سمت خارج نیز عیناً وارد کنید.
4. برای هر دو طرف، نام رابط و Subnet ID یکسان باشد؛ IPهای تونل از دو سر متفاوت شبکهٔ `/30` باشند.
5. از بخش Manage تونل را بسازید و سپس Start کنید. در هر دو سرور Status را ببینید.
6. برای اطمینان، ارتباط IP تونل و انتقال سرویس موردنظر را از ابتدا تا انتها بررسی کنید.

## نکات مهم

- GRE Key به‌تنهایی رمزگذاری ایجاد نمی‌کند؛ آن را محرمانه نگه دارید.
- حالت همهٔ پورت‌ها، ترافیک همهٔ پورت‌ها به‌جز ۲۲ را از تونل عبور می‌دهد؛ پیش از فعال‌کردن آن، نیازهای فایروال و سرویس‌ها را بررسی کنید.
- برای عبور تونل، پروتکل GRE (شمارهٔ ۴۷) باید در هر دو سرور و فایروال ارائه‌دهنده مجاز باشد.
- تغییر IP، کلید، subnet یا مشخصات هویتی ممکن است نیازمند هماهنگ‌کردن/ساخت دوبارهٔ رابط در هر دو سرور باشد.
- پیش از استفاده روی سرور اصلی، از تنظیمات فایروال و دسترسی SSH خود نسخهٔ پشتیبان داشته باشید.
- این اسکریپت قوانین شبکهٔ سرور را تغییر می‌دهد؛ آن را فقط روی سرورهایی اجرا کنید که مدیریتشان با شماست.
